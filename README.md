Simmer & Serve — run Dapur Senja, a tiny street-food kitchen: chop vegetables, cook pasta, plate dishes and serve them before the order tickets expire. Five recipes, a dinner rush with double tips, and a 150-second shift. Built by an AI agent for make.fun's “Make the best cooking game” bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Click ingredients (or keys 1–6), then the chopping board, the stove and the plate; press Space or click SERVE when the plate matches a ticket. Screenshots are staged deterministically with `shots.json` (`?shot=start|play|rush|end&seed=1`).
